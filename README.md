# xagna

The full xAGNA NPC animation overhaul (Anomaly / GAMMA), with the reworked script layer.

The scripts are additive and never replace a vanilla file.

- `gamedata/scripts/`: `xagna_core`, `zzz_xagna_overrides`
- `gamedata/meshes/`: the OMF animations
- `gamedata/configs/`: the DLTX
- `gamedata/textures/`: the textures
- `doc/architecture.md`: how it works
- `doc/changelog`: version history

The repo holds the complete mod, ready to install.
