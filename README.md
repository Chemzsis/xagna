# xagna

The full xAGNA NPC animation overhaul for Chemzs (Anomaly / GAMMA), with the reworked script layer.

Chemzs owns the mod and authors the animations (OMF) and configs (DLTX). Damian provides the hosting and the coding. The scripts are additive and never replace a vanilla file.

- `gamedata/scripts/`: `xagna_core`, `zzz_xagna_overrides`
- `gamedata/meshes/`: Chemzs's OMF animations
- `gamedata/configs/`: Chemzs's DLTX
- `gamedata/textures/`: Chemzs's textures
- `doc/architecture.md`: how it works
- `doc/changelog`: version history

The repo holds the complete mod, ready to install.
